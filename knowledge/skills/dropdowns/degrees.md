# Degree dropdown vocabulary

Canonical degree names and the variant strings we've seen in employer dropdowns. Agents should try these variants in order against the dumped options, and **append** new variants they discover.

Format: one canonical heading per degree, followed by a `Variants:` line (Python-list style for easy parsing if we ever want to).
